CYBERSECURITY MADE CLEAR FOR EVERYONE

CYBERLUCID is a free, beginner-friendly cybersecurity education platform built for everyday people — not just cybersecurity professionals.

The goal is simple: help people understand the threats they encounter online, recognize warning signs, protect themselves, and become harder to trick. No technical background is required. AI · AUTONOMOUS SYSTEMS · FLIGHT SIMULATION

AI Plane Flight Agent

NATURAL-LANGUAGE FIXED-WING CONTROL

AI Plane Flight Agent is an experimental multi-agent system that allows a simulated fixed-wing aircraft to be controlled using plain English.

Instead of manually programming every waypoint, an operator can describe a mission such as "Survey camp a then camp b and return home" or "Fly a racetrack heading north for 3 laps." The system interprets the request, converts it into structured flight actions, validates the mission against configured safety limits, executes the commands through MAVLink, and generates readable flight summaries.

Everything runs inside an ArduPlane SITL simulation, making the project suitable for experimentation, development, and research without requiring a physical aircraft.

01 / UNDERSTAND

Flight Agent

Interprets natural-language flight instructions and determines the requested actions.

02 / PLAN

Mission Planner

Breaks complex requests into smaller executable mission steps and flight patterns.

03 / VALIDATE

Safety Validator

Checks altitude, airspeed, landing points, and known hazards before execution.

04 / EXECUTE

MAVLink Execution

Uploads commands to the simulated aircraft and monitors mission execution in the background.

The system supports multi-step missions, short obstacle- avoidance detours, runway-aligned landing approaches, racetracks, figure-eights, lawnmower surveys, mission pausing and resuming, telemetry monitoring, flight reports, and learned operator preferences.

A single executor thread processes commands sequentially, helping prevent contradictory commands from being sent to the aircraft at the same time.
